iShare — GOING ONLINE
(No networking knowledge needed. Just follow the steps.)

What are we doing?
The app runs on your computer, and we make it reachable from the
internet so a friend can open it too. No router port forwarding,
no IP settings.


================================================================
WAY 1 — EASIEST (about 1 minute, no account)
Works while your computer is on and the window stays open.
This is now automatic: run.bat starts the tunnel for you.
================================================================

1) Install Node.js (once).
   If you don't have it: https://nodejs.org
   Press the green "LTS" button and install.

2) Get cloudflared (once).
   Download this file:
   https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe
   Rename it to "cloudflared.exe" and put it in the P2P_Share folder,
   next to run.bat.
   If Windows shows an "unknown publisher" warning, choose
   "Run anyway" / "Keep".

3) Double-click "run.bat".
   A black window opens. Leave it open.
   After a few seconds it prints:

     Your public link (copied to the clipboard):
     https://something-random.trycloudflare.com

   That is your internet address. It is already copied to your
   clipboard. If not, select it and copy it.

4) Send that link to your friend.
   Both of you open it.
   One person presses "Create a room" and tells the other the
   6-character code. The other enters it. Once connected you can
   send files and text.

IMPORTANT:
- The black window must stay open. Closing it ends the tunnel.
- The address changes every time you start; send the new one.
- If the computer sleeps, the connection drops. Turn off sleep mode.

Note: if cloudflared.exe is missing, run.bat starts the site in
local-only mode and prints the download link. Everything still
works at http://localhost:3000 on that computer.

To start without the tunnel on purpose:
   run.bat --local


================================================================
WAY 2 — KEEP IT ONLINE WHILE YOUR COMPUTER IS OFF
(free account, Render.com — the address stays the same)
================================================================

1) Create a free account at https://github.com
2) Sign in to https://render.com with GitHub (free).
3) Upload this project to GitHub:
   - On GitHub: "New repository" → give it a name → "Create".
   - On the next page open "uploading an existing file".
   - Drag the files from INSIDE the P2P_Share folder.
     Do NOT upload node_modules or the .env file.
   - Press "Commit changes".
4) In Render: "New" → "Web Service" → pick your GitHub project.
5) Settings:
   Build Command:  npm ci
   Start Command:  npm start
   Health Check:   /healthz
   Plan: Free
6) Press "Create Web Service" and wait (3-5 minutes).
7) Render gives you an address like https://....onrender.com.
   Send that to your friend. It keeps working while your
   computer is off.

NOTE: Render's free plan sleeps after 15 minutes without use.
The first visit can take 30-60 seconds. Be patient.


================================================================
IF THE CONNECTION FAILS (rare)
================================================================

If a device says "Could not connect":
1) Press the retry button next to that device.
2) Make sure both sides are on the same link.
3) If it still fails, one of the networks is probably blocking P2P.
   The fix is a TURN server. That requires a separate server and a
   more technical setup; see the "TURN configuration" section in
   README.md. Router/modem settings will not fix this.


================================================================
SAFETY — 3 RULES
================================================================

1) Give the room code only to the person you want in the room.
   Anyone with the code can join.
2) Close the tab when you are done. The room is deleted automatically.
3) Do not accept files from people you do not know.

ONE-SENTENCE SUMMARY
================================================================
